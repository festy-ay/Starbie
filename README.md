# Starbie

A star-shaped ESP32-C3 PCB with an OLED display, an MPU6050 motion sensor and a DHT11 sensor.

## Credits
This project is based on the Starbie guide by SharKing Studios:
https://github.com/SharKingStudios/Starbie

## What I changed
- Added a battery connector and a slide switch
- Added a second reset button
- Added mounting holes
- Added silkscreen artwork (starfish and waves) and a "Starbie" label

## What's in this repo
- KiCad files (.kicad_pro, .kicad_sch, .kicad_pcb)
- gerbers/ (manufacturing files)
- Imported Libraries (XIAO ESP32 Lbraries and co.)
- BOM.csv (parts list)
